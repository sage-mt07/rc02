  1: # Basic Produce and Consume Example
  2: 
  3: This sample pairs a simple producer and consumer using **Kafka.Ksql.Linq**.
  4: `Program.cs` registers `BasicMessage` with `[Topic]` and demonstrates
  5: sending a record then retrieving it with `ForEachAsync`.
  6: 
  7: This example corresponds to [getting-started.md](../../docs/getting-started.md)
  8: section *3. POCO属性ベースDSL設計ルール*.
  9: 
 10: ## Prerequisites
 11: - .NET 8 SDK
 12: - Docker
 13: 
 14: ## Run Steps
 15: 1. Start Kafka and ksqlDB:
 16:    ```bash
 17:    docker-compose up -d
 18:    ```
 19: 2. Run the program:
 20:    ```bash
 21:    dotnet run --project .
 22:    ```
 23: 
 24: Query details are visible in debug logs when `LogLevel: Debug` is enabled
 25: in `appsettings.json`.
