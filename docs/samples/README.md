# サンプルガイド（読みやすさ最優先）

## 目的 / 想定読者 / 成果物
- 目的: Kafka.Ksql.Linq の使い方を最短で把握できる最小サンプルを提供する
- 想定読者: 初見の開発者、評価担当、導入検討のPM
- 成果物: 小さく、読めば動かし方が分かるディレクトリ単位のサンプル群

## 方針
- 1サンプル = 1目的（副作用を増やさない）
- 依存は最小（補助関数よりもコード直書きで可読性を優先）
- 実行手順は冒頭に3行で書く（前提/コマンド/期待）
- 期待結果（ログ/画面出力）は抜粋で提示

## どこにあるか
-  … 教材としてのサンプル（実行シナリオ重視）
-  … 実用寄りの断片サンプル（APIの最小利用）

代表サンプル
-  … 最小のプロデュース/コンシューム
-  … 失敗時のDLQ/Retryの挙動
-  … ウィンドウとEMIT FINALの違い
-  … Topic拡張の最小利用
